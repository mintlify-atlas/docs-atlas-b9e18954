`build_universe.mjs` builds the per-month basket universe by fetching monthly OHLCV data from Binance for all USDT spot pairs, ranking them by the **previous** calendar month's quote volume, applying eligibility filters, and writing the resulting basket lists to `scripts/common/universe.json`.

## Usage

```bash
node scripts/common/build_universe.mjs [--top 20] [--from 2020-09] [--to 2026-09] [--refresh]
```

## Flags

<ParamField path="--top" type="number" default="20">
  Number of pairs to include per month. The script picks the top N symbols by prior-month quote volume after all eligibility filters have been applied.
</ParamField>

<ParamField path="--from" type="string" default="2020-09">
  First month to generate, in `YYYY-MM` format. Months before this value are skipped even if Binance candle data is available.
</ParamField>

<ParamField path="--to" type="string" default="2026-09">
  Last month to generate, in `YYYY-MM` format. Months after this value are skipped.
</ParamField>

<ParamField path="--refresh" type="boolean">
  Re-download Binance monthly candles from the exchange, ignoring any existing `tmp/binance_monthly_usdt.json` cache. Without this flag the script reuses the cached file if it exists.
</ParamField>

## Outputs

| File | Description |
|---|---|
| `scripts/common/universe.json` | Basket lists for every generated month, including `rankedBy`, `basket`, `volumeUsdTop1`, and `volumeUsdCutoff` fields with volume metadata. |
| `tmp/binance_monthly_usdt.json` | Raw Binance monthly candle cache written after each full download. This directory is gitignored; the file persists between runs to avoid re-fetching ~700 requests. |

## Exit Codes

| Code | Meaning |
|---|---|
| `0` | Success — all baskets are fully built and every coin in them has a verified Yahoo ticker entry. |
| `2` | One or more symbols appear in baskets but have not yet been checked by `resolve_yahoo_tickers.mjs`. Run the resolver and repeat until this list is empty. |

## Eligibility Filters

The script applies the following filters before ranking. Any symbol that fails a filter is excluded from basket consideration for that month:

- **90-day minimum listing age** — `monthStart − firstSeen[symbol] >= 90 days`. Prevents very new listings from entering the basket before they have meaningful liquidity history.
- **Stablecoins and fiat bases excluded** — symbols whose base matches a hard-coded set including `USDT`, `USDC`, `BUSD`, `FDUSD`, `DAI`, `EUR`, `GBP`, `TRY`, and many others are dropped.
- **Leveraged tokens excluded** — symbols whose base ends in `UP`, `DOWN`, `BULL`, or `BEAR` are removed.
- **Wrapped and staked derivatives excluded** — a fixed set of `WBTC`, `WBETH`, `BETH`, `STETH`, `WSTETH`, `CBETH`, `RETH`, `BNSOL`, `BBSOL`, `JITOSOL`, `MSOL`, `PAXG`, `XAUT`, `BTCST`, `BTCB`, `RENBTC`, `TBTC`, `SBTC`, `WETH`, `ETHW`, and `BNBX` is blocked regardless of volume.
- **No Yahoo ticker** — coins with a `null` entry in `yahoo_tickers.json` are excluded. Coins not yet present in the file are treated as unresolved (see exit code 2).
- **Yahoo history starts too late** — if the Yahoo ticker's `since` date is less than 7 days before the start of the month, the coin is excluded for that month only.
- **`badMonths` entries** — coins whose `yahoo_tickers.json` entry contains a `badMonths` array are excluded for the specific months listed there (set by `verify_yahoo_tickers.mjs`).

## Dependencies

- [`ccxt`](https://github.com/ccxt/ccxt) — used to load Binance spot markets and fetch monthly OHLCV candles via the `binance` exchange class with rate limiting enabled.

<Note>
  This script typically needs to be run 2–3 times in a loop. On the first run it exits with code 2 listing unresolved symbols; after running `resolve_yahoo_tickers.mjs` some coins will be excluded (null ticker) and the next-ranked coins will need resolution too. Repeat until the script exits with code 0:

  ```bash
  node scripts/common/resolve_yahoo_tickers.mjs
  node scripts/common/build_universe.mjs
  # repeat until exit code is 0
  ```
</Note>
